# Draupnir

Encrypted backup daemon triggered by udev. Plug in your disk, backups happen automatically,
silently, and verifiably.

##  How it works

- **`draupnir`** - runs as root, watches for a specific disk UUID via udev, mounts it, and streams a backup through `tar -> zstd -> age` atomically. Started at boot as a systemd service.
- **`draupnir-reminder`**  - runs in your user session on a timer, reads the last backup timestamp, and sends a desktop notification if a backup is overdue.

Archives are named `backup-<unix_timestamp>.tar.zst.age` and stored directly on the disk. Old archives are rotated after each successful backup.

## Prerequisites

```sh
apt install age just zstd
```

## Quick start

### Generate an encryption key pair

```sh
just age_keypair
```

### Interactively generate config and systemd unit files

```sh
just install user       # reminder for current user only
just install global     # reminder for all users
```

### Configuration

`/etc/draupnir/config.toml` (generated by `just setup`):

```toml
uuid                  = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"    # lsblk -o NAME,UUID,FSTYPE
mountpoint            = "/mnt/draupnir"
destination           = "/mnt/draupnir/backups"
sources               = ["/home", "/etc"]
age_pubkey            = "age1..."                                 # just age_keypair
threshold_days        = 7                                         # days before overdue notification
keep                  = 5                                         # archives to keep

# Optional
compression_level = 3                                             # zstd level 1-22
exclude = [".cache", "node_modules", "target"]                    # basenames, any depth
```

### Restore

```sh
# Mount your backup disk manually, then:
just restore

Or manually:

age -d -i ~/.config/draupnir/draupnir_age_key.txt backup-<ts>.tar.zst.age \
  | zstd -d \
  | tar -x -C /path/to/restore/
```

### Useful commands

```sh
just status    # last backup time and next due date
just verify    # decrypt and count entries in the latest archive
just logs      # stream draupnir service logs
just check     # cargo clippy -D warnings
```

## Security

- Archives are encrypted with `age` before hitting the disk. The daemon only knows the **public key**.
- The private key lives at `~/.config/draupnir/draupnir_age_key.txt` (chmod 600). Keep it safe, without it, existing archives cannot be decrypted.
- The disk is mounted `nosuid,nodev,noexec`.
- `just uninstall does **not** delete the private key or the archives`.

## Development

just build     # cargo build --release
